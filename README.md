# ขอบฟ้ากว้าง · Interactive Prototype

เปิด `index.html` ด้วย Microsoft Edge, Chrome หรือ Firefox ได้ทันที ไม่ต้องติดตั้งหรือเชื่อมต่ออินเทอร์เน็ต ไฟล์เดียวรวม HTML, CSS, JavaScript และไอคอนทั้งหมด

## วิธีทดลองให้ครบสองบทบาท

1. เริ่มที่ผู้ปกครอง / บุคคลพิเศษ เลือกโปรไฟล์ต้นหรือพิมที่หน้าภาพรวม
2. ค้นหางาน ดูรายละเอียดและเหตุผลของคะแนน สมัครงานพร้อมยินยอมเปิดเผยข้อมูล
3. สลับเป็นสถานประกอบการด้วยปุ่มด้านบน เปิดผู้สมัครและการจ้างงาน เริ่มพิจารณาและนัดสัมภาษณ์
4. สลับกลับฝั่งผู้สมัครเพื่อยืนยันนัด จากนั้นใช้ฝั่งนายจ้างส่งข้อเสนองาน แล้วฝั่งผู้สมัครยอมรับ
5. บันทึกติดตามหลังเริ่มงานในช่วง 1 / 2 / 3 เดือน ส่งแบบประเมิน และดูรายงานหรือส่งออก CSV
6. ทดลองเรียนให้ครบสามบท ทำแบบประเมิน และดาวน์โหลดใบรับรองตัวอย่าง ทักษะที่ผ่านจะเพิ่มในโปรไฟล์

สถานประกอบการหลักในตัวอย่างคือ “กรีนสเปซ รีเทล” จัดการได้เฉพาะประกาศของบริษัทนี้ บริษัทอื่นเป็นตัวอย่างสำหรับการค้นหา ไม่ได้มีบัญชีฝั่งนายจ้างเพิ่มเติม

## ขอบเขตการจำลอง

- ข้อมูลตัวอย่างบันทึกด้วย localStorage เฉพาะเบราว์เซอร์/อุปกรณ์นี้ ไม่มีฐานข้อมูลกลาง การส่งข้อความภายนอก อีเมล SMS หรือการจ้างงานจริง
- บัญชีและการยินยอมเป็น UX จำลอง ไม่มีการพิสูจน์ตัวตนหรือระบบสิทธิ์ระดับเซิร์ฟเวอร์
- คะแนนงานใช้สูตรอธิบายได้: พื้นฐาน 30 + สัดส่วนทักษะที่ตรง × 50 + จังหวัดตรง 20 ไม่ใช่โมเดล AI ที่ผ่านการฝึกหรือรับรอง
- ข้อความเป็นห้องสนทนาตัวอย่างระหว่างสอง Role ในครอบครัวและสถานประกอบการหลัก ไม่มีการส่งถึงบุคคลจริง
- บทเรียน ข้อมูลบริษัท บุคคล และใบรับรองเป็นตัวอย่างทั้งหมด
- KPI คำนวณจากข้อมูลทดลองขนาดเล็ก ตัวหารที่ยังไม่มีข้อมูลแสดงว่าไม่มีข้อมูล เป้าหมาย uptime, adoption และประสิทธิภาพจริงยังไม่มี telemetry
- อัตราความตั้งใจกลับมาร่วมงานไม่ใช่อัตรากลับมาร่วมงานจริง หน้ารายงานระบุข้อแตกต่างนี้ไว้
- ธีม AI Support ในหน้า 3 ยังไม่มีข้อกำหนดระบบ AI รายละเอียด จึงใช้การสนับสนุนผ่านบทเรียน FAQ และคำขอคำปรึกษา ไม่แสดงว่าเชื่อมต่อ AI จริง
- หากต้องการเริ่มใหม่ ใช้การตั้งค่า → คืนค่าข้อมูลตัวอย่าง

## Animation

- เปลี่ยนหน้าและสลับ Role: หัวข้อและการ์ดค่อย ๆ ปรากฏตามลำดับสั้น ๆ
- หน้าต่างรายละเอียด / แบบฟอร์ม: เลื่อนและขยายเล็กน้อยพร้อมฉากหลังจางเข้า
- ปุ่มและการ์ด: ตอบสนองต่อการชี้และการกด โดยไม่เปลี่ยนขนาดพื้นที่จัดวาง
- กราฟและแถบความก้าวหน้า: ขยายไปยังค่าข้อมูลจริง
- ข้อความใหม่และแจ้งผลการทำรายการ: ปรากฏด้วยการเคลื่อนไหวสั้น ๆ
- ภาพประกอบเคลื่อนไหวครั้งเดียว ไม่มี Animation วนต่อเนื่อง
- ปิดการเคลื่อนไหวได้ที่ การตั้งค่า → ลดการเคลื่อนไหวและ Animation และรองรับ prefers-reduced-motion ของอุปกรณ์อัตโนมัติ
- Animation ไม่หน่วงการบันทึกข้อมูล การตรวจแบบฟอร์ม หรือการเปิด/ปิดหน้าต่าง
